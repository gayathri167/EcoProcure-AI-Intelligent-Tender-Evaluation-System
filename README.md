# ♻️ EcoProcure AI – Intelligent Tender Evaluation System

## 📌 Overview
EcoProcure AI is an AI-powered system designed to automate the evaluation of government tenders for plastic waste management. It reduces manual effort, improves transparency, and enables faster decision-making.

---

## 🚨 Problem Statement
Government agencies currently evaluate tenders manually, which is:
- Time-consuming
- Error-prone
- Difficult to compare multiple bidders
- Lacks transparency

---

## 💡 Solution
EcoProcure AI uses Natural Language Processing (NLP) and rule-based scoring to:
- Extract requirements from tender documents
- Evaluate bidder eligibility
- Assign scores and rank bidders
- Detect unrealistic or fraudulent claims

---

## ⚙️ Features
- 📄 PDF Upload and Processing  
- 🤖 Automated Requirement Extraction (capacity, experience)  
- 🧾 Bidder Evaluation System  
- 📊 Scoring (0–100)  
- 🏆 Ranking and Top Bidder Highlight  
- 🚩 Fraud Detection (unrealistic claims)  
- 📈 Data Visualization (charts)  
- 🧠 Explainable AI (clear decision reasons)  

---

## 🛠️ Tech Stack
- Python  
- Streamlit (UI)  
- pdfplumber (PDF parsing)  
- Regex (NLP extraction)  
- Pandas (data handling)  
- Matplotlib (visualization)  

---

## 🔄 How It Works
1. Upload tender document (PDF)  
2. Extract requirements using NLP  
3. Enter bidder details  
4. Evaluate bidders using scoring logic  
5. Rank bidders and highlight the best one  
6. Detect fraudulent or unrealistic inputs
